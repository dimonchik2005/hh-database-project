# HH Database Project

Проект для получения данных о работодателях и вакансиях, сохранения этих данных в PostgreSQL и работы с ними через SQL-запросы.

## Описание проекта

Проект получает данные о вакансиях с hh.ru или из локального JSON-файла, создает базу данных PostgreSQL, создает таблицы работодателей и вакансий, загружает данные в таблицы и предоставляет консольный интерфейс для просмотра информации.

Если API hh.ru недоступен или блокирует запросы, проект использует файл `data/hh_vacancies.json`.

## Реализованный функционал

В проекте реализовано:

* получение данных через API hh.ru;
* загрузка данных из JSON-файла при недоступности API;
* автоматическое создание базы данных PostgreSQL;
* автоматическое создание таблиц;
* таблица работодателей `employers`;
* таблица вакансий `vacancies`;
* связь таблицы вакансий с таблицей работодателей через внешний ключ;
* загрузка работодателей в базу данных;
* загрузка вакансий в базу данных;
* класс `DBManager` для работы с данными;
* консольное меню пользователя;
* тесты для основных модулей проекта.

## Настройка переменных окружения

В корне проекта нужно создать файл `.env`.

Пример:

```env
DB_NAME=hh_project
DB_USER=postgres
DB_PASSWORD=12345
DB_HOST=localhost
DB_PORT=5432
```

Файл `.env` не должен попадать в GitHub.

## Установка зависимостей

```bash
poetry install
```

## Запуск проекта

```bash
poetry run python main.py
```

При запуске программа:

1. создает базу данных;
2. создает таблицы;
3. загружает данные о работодателях и вакансиях;
4. запускает консольное меню.

## Команды меню

```text
1. Показать компании и количество вакансий
2. Показать все вакансии
3. Показать среднюю зарплату
4. Показать вакансии с зарплатой выше средней
5. Найти вакансии по ключевому слову
0. Выйти
```

## Класс DBManager

В классе `DBManager` реализованы методы:

* `get_companies_and_vacancies_count()` — получает список компаний и количество вакансий у каждой компании;
* `get_all_vacancies()` — получает список всех вакансий с названием компании, названием вакансии, зарплатой и ссылкой;
* `get_avg_salary()` — получает среднюю зарплату по вакансиям;
* `get_vacancies_with_higher_salary()` — получает вакансии с зарплатой выше средней;
* `get_vacancies_with_keyword()` — получает вакансии по ключевому слову в названии.
